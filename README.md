# colors-rs
Simple color package for rust.

### Colors
* `.black()` — black text
* `.red()` — red text
* `.green()` — green text
* `.yellow()` — yellow text
* `.blue()` — blue text
* `.purple()` — purple text
* `.cyan()` — cyan text
* `.white()` — white text

### Styles
* `.italic()` — italic text
* `.bold()` — bold text
* `.underlined()` — underlined text
